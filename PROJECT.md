# Skilling — подготовка к техническим собеседованиям в стиле Duolingo

> Главный документ проекта. Если вы человек или AI-ассистент и только открыли репозиторий — начните отсюда.

## Цель

Перестать «плавать» в теории на собеседованиях на позиции Middle Frontend / Full-Stack (React, Next.js, Node.js, TypeScript).

Опыта больше трёх лет, практика есть, а сформулировать теорию вслух не получается. Читать теорию подряд не помогает: материал забывается. Поэтому вместо чтения нужны:

- **активное вспоминание** — отвечать на вопрос, а не перечитывать ответ;
- **интервальные повторения** — возвращаться к вопросу тогда, когда он начинает забываться;
- **ежедневная привычка** — короткие сессии, стрик и напоминания, как в Duolingo.

**Критерий успеха:** босс-техчек (10 случайных вопросов из всего банка) проходится стабильно на ≥80%, причём в открытом формате, то есть ответ формулируется своими словами.

## Описание

Сайт, где вместо уроков — **техчеки**: короткие сессии по 5–10 вопросов. Вопросы собраны в темы, темы разбиты на уровни. Ошибки не теряются: они переносятся в следующий этап и возвращаются по графику повторений. Когда пройдены все уровни, открывается **босс-техчек**, его можно перепроходить сколько угодно.

Один и тот же вопрос показывается в разных форматах: сначала тест (узнавание), потом открытый ответ текстом или голосом (воспроизведение). На собеседовании нужно именно воспроизведение.

LLM для проверки ответов **не используется** (решение от 2026-11-24): открытые ответы проверяются чек-листом ключевых пунктов.

### Где хранятся вопросы: в репозитории или в базе?

**Источник правды — JSON-файлы в репозитории**, а в базу они копируются скриптом.

- Вопросы удобно писать и генерировать с AI прямо в файлах, видеть изменения в git и откатывать.
- `npm run questions:validate` проверяет каждый вопрос по схеме ([`src/lib/questions/schema.ts`](src/lib/questions/schema.ts)) до того, как он попадёт к пользователю.
- `npm run questions:seed` (этап 2) делает upsert в таблицы `topics` и `questions` в Supabase. Вопросы, удалённые из файлов, в базе не удаляются, а получают `is_active = false`, чтобы не потерять историю ответов.
- **Прогресс пользователя** (ответы, повторения, уровни, босс, стрик) хранится только в Supabase.

Формат вопроса и правила их написания: [`content/questions/README.md`](content/questions/README.md).

## Механика

Все числа вынесены в [`src/lib/game/config.ts`](src/lib/game/config.ts).

### Уровни (тренировочный этап)

- Каждая тема разбита на уровни по 5–10 вопросов (поле `level` у вопроса).
- Уровень — это один техчек: вопросы уровня плюс ошибки, перенесённые с прошлых уровней.
- **Уровень пройден**, если правильных ответов ≥ 70%. Иначе он не засчитан, и его нужно пройти заново.
- Вопросы, на которые ответили неправильно, добавляются в следующий этап.
- Следующий уровень открывается после прохождения текущего.

### Интервальные повторения (SM-2)

- У каждого вопроса для пользователя хранится: дата следующего показа (`due_at`), интервал, коэффициент лёгкости (`ease`), число правильных ответов подряд.
- Правильный ответ увеличивает интервал (1 → 3 → 7 → 21 день…), ошибка возвращает вопрос на завтра.
- Ежедневное повторение — все вопросы, у которых наступил `due_at` (не больше 20 в день).
- Стадии вопроса: `new` → `learning` → `review` → `mastered` (интервал ≥ 21 дня).

### Выбор формата

- Пока вопрос новый или с ошибками — форматы узнавания: тест, правда/ложь, «что выведет код», порядок.
- После двух правильных ответов подряд — открытый ответ: текстом или голосом.
- Формат выбирается случайно из разрешённых для вопроса (поле `formats`).

### Босс-техчек

- Открывается, когда пройдены все уровни всех тем.
- 10 вопросов из всего банка: половина — «слабые» (больше ошибок, низкий `ease`), половина — случайные.
- Пройден при ≥ 80%. Перепроходить можно бесконечно, каждый раз набор вопросов новый.
- Ошибки в боссе тоже уходят в повторения.

### Привычка

- **Стрик** — дни подряд хотя бы с одним техчеком (таблица `daily_activity`).
- **XP** — очки за правильные ответы, бонус за открытые форматы.
- **Напоминания** через Telegram-бота: «у вас 12 вопросов на повторение». Время задаётся в профиле.

## Форматы ответов

| Формат | Как выглядит | Как проверяется |
|---|---|---|
| `single_choice` | один правильный вариант из 4 | автоматически |
| `multiple_choice` | несколько правильных вариантов | автоматически, засчитано только при полном совпадении |
| `true_false` | набор утверждений «верно / неверно» | автоматически, нужно ответить верно на все |
| `code_output` | «что выведет этот код» — выбор из вариантов | автоматически |
| `ordering` | расставить шаги в правильном порядке | автоматически |
| `open_text` | открытый ответ текстом | чек-лист ключевых пунктов |
| `open_voice` | открытый ответ голосом | распознанный текст + чек-лист |

### Проверка открытых ответов чек-листом

1. Пользователь отвечает текстом или голосом, не видя подсказок.
2. После ответа показываются эталонный ответ и список ключевых пунктов (`keyPoints`).
3. Пользователь честно отмечает пункты, которые упомянул.
4. Отмечено ≥ 70% пунктов — ответ засчитан. Меньше — ошибка: показывается объяснение, вопрос уходит в повторение.
5. В `attempts.score` сохраняется доля отмеченных пунктов, чтобы видеть прогресс по вопросу.

### Голосовой ответ (Web Speech API)

- Бесплатно и без своего сервера: используется встроенный в браузер `SpeechRecognition`.
- Работает в Chrome, Edge и Safari. В Firefox его нет: формат `open_voice` там автоматически заменяется на `open_text`.
- Язык распознавания (`ru-RU`, `uk-UA`, `en-US`) выбирается в профиле.
- Распознанный текст можно поправить перед проверкой, дальше — тот же чек-лист.
- В Chrome звук распознаётся на серверах Google: это стоит указать в интерфейсе.
- Цель формата — тренировать то, что реально нужно на собеседовании: говорить вслух.

## Схема базы (Supabase)

Подробно — в [`supabase/migrations/20261124000000_init.sql`](supabase/migrations/20261124000000_init.sql).

| Таблица | Что хранит |
|---|---|
| `topics`, `questions` | копия банка вопросов из `content/` (читают все, пишет только сидинг) |
| `profiles` | имя, часовой пояс, время напоминания, Telegram chat id, язык голоса |
| `user_question_state` | состояние повторения каждого вопроса: `due_at`, `ease`, интервал, ошибки |
| `level_progress` | статус уровня по теме: закрыт / открыт / пройден, лучший результат |
| `level_runs` | каждое прохождение уровня: какие вопросы, сколько правильных |
| `boss_runs` | каждое прохождение босса |
| `attempts` | каждый ответ: формат, верно или нет, доля пунктов чек-листа, сам ответ |
| `daily_activity` | ответы и XP по дням — для стрика |
